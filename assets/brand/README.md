# Alice brand assets

A white rabbit with one straight ear and one folded into a question mark: curious, sly, Wonderland.
Solid angular forms, like a playing-card pip. One eye is a diamond, the other a spiral (the way into another world).

| File | Use |
|---|---|
| `alice-mark.svg` | the rabbit alone, transparent background |
| `alice-mark-mono.svg` | one-color version (print, stamps, embossing) |
| `alice-icon.svg` | app icon / avatar (black rounded tile) |
| `alice-logo.svg` / `alice-logo-dark.svg` | mark + wordmark + tagline, light / dark backgrounds |
| `alice-card.svg` | "Ace of Rabbits" playing card |
| `alice-social.svg` | 1280×640 social preview |
| `alice.ico` | Windows icon (16–256 px), used by `alice.exe` |
